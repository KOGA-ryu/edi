## 5. Cadence & conventions

- **Light cadence.** Plan → build → test → commit per slice, inline. Run a
  design/critique workflow at *phase starts* and an adversarial pass at *risky
  joints* (new seams/formats/signals). The heavyweight R-track protocol is retired.
- **The green gate, every slice:** `cmake --build build && ctest --test-dir build`
  fully green + the no-JSON/no-qml scan, before each commit.
- **Division of labor in the lab (user, locked):** the **human composes by
  CLICKING** (palette/inspector/binding picker); **the AI edits the TOML** ("toml
  is for ai to edit"). Both edit the one op stream; UI verbs sync the TOML +
  `emit opsStreamChanged`.
- **Persistence pattern for new document data:** document-level vector + free-
  function ops + a `DraftingCommand` arm + additive/tolerant MessagePack (missing
  key ⇒ default, NO version bump). The recipe op stream is a window member
  (`m_opsStream`), mutated only via its verbs.
- **The user owns the look.** Flag visible UI changes; keep heavy polish out unless
  asked. Re-bless `tests/golden/*.png` via
  `EDI_BLESS_GOLDEN=1 ./build/edi_shell_window_tests` after an intended look change.

## 7. Open threads & gotchas

- **PUSH:** the session's feature work is on `origin`; only this handoff commit is
  local at write time — push it (`git push`).
- **Op-stream UI signal safety (the lab's subtle part):** inspector widgets commit
  on USER-only signals (`editingFinished`/`activated`/`clicked`), never ones a
  programmatic refresh fires, so the post-edit re-render can't loop. The Steps
  inspector REBUILDS field widgets only on selection change or a field-shape/
  bound-state flip (never a value commit) — so a rebuild is never mid-signal. The
  binding menu DEFERS its action via `QTimer::singleShot(0)` (it would otherwise
  delete the spinbox mid-context-menu-event).
- **R2 OBJ golden** is byte-pinned in `tests/edi_craft_smoke.py` but **not yet
  eyeballed** in a 3D viewer — the golden guards drift, not correctness. View once.
- **Pop-out windows are framed** (Qt::Tool); a frameless drag skin is the polish.
- **Custom-craftsman params are untyped strings** in the `Script` op's param bag;
  the craftsman coerces (the manifest declares the intended type).
- **Test gotchas (CLAUDE.md):** `rebuildGeometryEditor` retires spins with
  `deleteLater()` — flush `QEvent::DeferredDelete` before widget lookups. Hold
  document data by VALUE across an undo/redo (a `DraftingBlock&`/`RecipeOp&` into a
  document vector dangles after the vector repopulates).
- **Stale-lock recovery:** if `.git/index.lock`/`HEAD.lock` blocks a commit, confirm
  it's a zero-byte stale file (only `fsmonitor--daemon` git running) before removing.
