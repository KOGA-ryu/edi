# Extruded figure — the extrude spine, end to end

The minimal proof for the `AddExtrudedProfile` → `AddPrism` extrude spine
(BL-01/03/04). Where the doric sample exercises the lathe (revolve a
profile), this one exercises the EXTRUDE (sweep a planar footprint up +z).

- `extruded_figure_ops_compiled.toml` — a COMPILED op stream: one `AddPrism`
  carrier, exactly the shape the C++ resolve pass serializes after lowering an
  `AddExtrudedProfileOp`. Its footprint is a hand-authored L-bracket (6
  physical x/y points), extruded `height=3` from `base_z=1`.
- `extruded_figure.obj` — the OBJ mesh proof, generated by
  `python3 tools/blender/edi_craft.py --obj-out=… extruded_figure_ops_compiled.toml`.
  12 verts (bottom cap at z=1, top cap at z=4), 8 faces (2 caps + 6 side
  quads). The z-extent is exactly the op height — the proof is honest about
  dimension, and (like every craftsman proof) it is computed PURELY, with no
  Blender required. Pinned byte-for-byte by `tests/edi_craft_smoke.py`.
